# Contributing

Thanks for helping Stillday stay small and useful.

1. Fork the repository and create a focused branch.
2. Run `npm install` and `npm test`.
3. Keep new features local-first and dependency-light.
4. Open a pull request that explains the user-facing reason for the change.

Bug reports should include the Windows version, Stillday version, and concise reproduction steps. Please do not include private notes or exported backup contents.
